# Iterm Cheatsheet

```sh
CMD + SHIFT + ENTER     maxmize active panel
CTRL + CMD + ↓ / ↑      resize

# mac + ozsh macos plugins
cdf                     cd to the current Finder window
cofd                    Open current dir in a Finder window
quicklook <file>        Open quicklook for file
showfiles               Show hidden files in Finder window dir
hidefiles               Hide hidden files in Finder
spotify                 Control Spotify
```
